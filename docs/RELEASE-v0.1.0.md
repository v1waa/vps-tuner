Первая версия **VPS Tuner** — desktop-приложение для администрирования Linux VPS по SSH.

### Скачать

- Windows x64: `windows-x64-setup.exe` или `windows-x64-portable.exe`.
- Linux x64: `.AppImage`, `.deb`, `.tar.gz`.
- Проверка загрузки: `SHA256SUMS.txt`.

### В этой версии

- Русский интерфейс; профили SSH, пароли и ключи с passphrase, контроль SSH fingerprint.
- Автоматический аудит ресурсов, портов, проектов, systemd, Docker/Compose и защиты.
- Управление службами, контейнерами и Compose; журнал операций и живой вывод.
- Базовые пакеты, Docker, администратор с SSH-ключом, Fail2ban, UFW с подтверждением после переподключения и таймером отката.
- PostgreSQL, MariaDB, Redis; сайты Nginx, Caddy HTTPS, боты/приложения из Docker или Git.
- AmneziaWG userspace, Xray VLESS+REALITY, WDTT/VK TURN. Отдельные AWG/Xray-клиенты и отзыв доступа; WDTT-пользователи в локальной панели через SSH-туннель.
- Архивы файлов, SQL dump, скачивание через SFTP, экспорт аудита, консоль Bash.

Автоустановка пакетов: Debian/Ubuntu. Клиенты приложения: Windows 10/11 и Linux x64. Для изменений на VPS нужен root или sudo без пароля. Приложение не является VPN-клиентом.

### Границы первой версии

OpenFlux доступен как экспериментальный внешний проект без отдельного автоматического установщика. Реальная проходимость белых списков зависит от оператора, транспорта и клиента; её проверяют отдельно. Нет импорта пользователей чужих панелей, автоматического расписания резервных копий и мастера восстановления. При частичной ошибке установки не удаляются уже созданные файлы и пакеты. Бинарники Windows без подписи издателя.

[Инструкция и описание мер защиты](https://github.com/v1waa/vps-tuner#readme).
